確認状態と調査範囲

「本文」は公式ページ本文を取得できたこと、「JS」はJavaScript主体のため見出しや画面入口までの取得であることを示す。「公式コード」「公式目次」「公式紹介」が付く場合、内容はその一次資料でも照合した。「検索のみ」は公式ページの検索情報は得られたが、直接取得できなかった候補である。

全掲載サイトのブラウザ操作・学習・推論の完走は検証していない。 ページの取得成功とアプリの動作成功は別である。認証、料金、API利用枠、端末・ブラウザ条件も全件は確認していない。レベル区分は本リンク集での目安で、提供者の公式分類とは限らない。言語は取得したページを基準にし、ブラウザ翻訳を公式日本語対応として数えていない。

対象は、機械学習そのものを見せる操作型教材、視覚解説、モデル・データの可視化ツール。一般的なBI製品、単にグラフを作るライブラリ、可視化のない講座、リンクだけの一般ブログは中心対象から外した。分類の幅を広く取った調査であり、世界中の全サイトの完全網羅を保証するものではない。

掲載サイトの補足

  • Seeing Theoryは、公式ページでアーカイブと明記されている。
  • TensorFlow Playgroundの取得ページは英語だった。日本語切替は今回確認できなかったため、公式日本語対応とは記載しない。
  • Diffusion Explainerの公式説明はpreset promptsでの実験を案内している。任意プロンプトを受け付ける自由生成サービスとしては紹介しない。
  • LITの公式ページでの現在の名称はLearning Interpretability Tool。古い資料ではLanguage Interpretability Toolと呼ばれることがある。
  • PAIRの日本語翻訳は有志翻訳として紹介する。原版すべての日本語化や、公式翻訳であることは主張しない。
  • R2D3の直接取得は522エラーとなった。公開終了とは断定せず、末尾の再確認候補に置いた。

授業・自習での組み合わせ

データサイエンス入門

Seeing Theoryで標本と確率を体験し、StatKeyで再標本化、Linear Regression / MLUで予測へ進む。最後にTrain, Test and Validation / MLUで学習と評価を分ける。

機械学習の基礎

Decision Trees / MLU → Random Forest / MLU → Bias-Variance Tradeoff / MLU → ROC & AUC / MLU。分類の仕組み、汎化、評価を一続きで扱う。

深層学習

TensorFlow Playground → Calculus on Computational Graphs: Backpropagation → Image Kernels / EV → CNN Explainer。最初に学習の挙動を観察し、その後に計算の内訳を読む。

自然言語処理・LLM

Embedding Projector → The Illustrated Transformer → Transformer Explainer → BertViz。ベクトル表現、構造、推論、Attentionの比較へ進む。BertVizで自作モデルを扱う段階ではNotebook等を準備する。
