文章から学習データを作る手順

以下は初期例文 You say goodbye and I say hello. での作成例。入力文を変更しても、同じ手順で上の表を作る。

  1. 小文字にそろえ、単語に分割する

    英字を小文字に変換し、ピリオドの前に空白を入れてから空白で分割する。ピリオドも1語として扱う。

    you | say | goodbye | and | i | say | hello | .

    日本語の入力例は分かち書き済み。この画面では形態素解析を行わない。

  2. 初めて現れた語にIDを割り当てる

    you → 0、say → 1、goodbye → 2 …と、出現順に登録する。2回目の say にも同じIDの1を使う。8個のトークンに対して、異なる語は7種類になる。

  3. 文章を単語ID列 corpus に置き換える

    corpus = [0, 1, 2, 3, 4, 1, 5, 6]

    「位置」は文章中の何番目か、「ID」はどの単語かを表す。例えば位置5の say のIDは1。IDの大小は意味の近さを表さない。

  4. 中心語を隠し、左右1語を入力にする

    位置1の say を中心語にすると、左の you と右の goodbye が周辺語になる。ウィンドウサイズ1は、左右それぞれ1語という意味。

    入力 contexts[0] = [0, 2]  # you, goodbye
正解 target[0]   = 1       # say

  5. 中心位置を1つずつ右にずらす

    次は say, and → goodbye。同様に末尾まで進める。先頭と末尾は左右の語がそろわないため中心語にしない。8トークンから 8 − 2 = 6 個の学習例を作る。

    contexts = [[0,2], [1,3], [2,4], [3,1], [4,5], [1,6]]
target   = [1, 2, 3, 4, 1, 5]

  6. 通常CBOWへ渡すone-hot表現を作る

    語彙数7に合わせた長さ7の配列を用意し、その単語のIDの位置だけを1にする。周辺語と正解をこの表現に変換してモデルへ渡す。

    you     (ID 0) → [1, 0, 0, 0, 0, 0, 0]
goodbye (ID 2) → [0, 0, 1, 0, 0, 0, 0]
say     (ID 1) → [0, 1, 0, 0, 0, 0, 0]

    正解は元の文章の中心語から作れる。これがCBOWを自己教師あり学習と呼ぶ理由。次の「CBOWの計算」タブで、周辺語から正解語を予測する処理を確認する。

通常CBOWのネットワーク構造

左右のone-hot入力は同じ W_in を共有する。取り出した2つのベクトルを平均し、全語彙のスコアから中心語の確率を求める。

丸の中の数値は現在の学習例の計算値。緑は入力で1となる位置、赤は正解語。正解ラベルはSoftmaxの出力と比較して損失を求めるために使う。
