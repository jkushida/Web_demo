今回の加算

共起パターンをベクトルの向きで比べる

cos(x, y) = (x・y) / (‖x‖ × ‖y‖)

似た共起パターンの単語を探す

検索語自身を除外。同点は単語ID順。0ベクトルとの類似度は、この実装では0として扱う。

共起行列と類似度の読み方

周辺語の回数を同じ行へ足し合わせる

注目位置を左から順に動かし、左右の周辺語ごとに C[注目語ID, 周辺語ID] を1増やす。同じ単語が複数の位置に現れた場合は、同じ行へ足し合わせる。

文頭・文末では存在する周辺語だけを数える。ノートブックと同様に文章全体を1本の列として扱うため、句点も数え、文の境界もまたぐ。

各行を単語ベクトルとして比較する

各行の成分は周辺語の出現回数。コサイン類似度は、そのパターンの方向の近さを表す。この非負の行列では0〜1となる。小さな例文で値が高くても、一般的な意味の近さまで保証しない。

前処理では連続する空白をまとめ、空文字を語彙に含めない。類似度の計算はノートブックと同じく、各ノルムに 1e-8 を加えてゼロ除算を防ぐ。

共起行列を作るコード

for idx, word_id in enumerate(corpus):
    for distance in range(1, window_size + 1):
        for pos in [idx - distance, idx + distance]:
            if 0 <= pos < len(corpus):
                co_matrix[word_id, corpus[pos]] += 1
