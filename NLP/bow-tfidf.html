何を1本のベクトルで表すかが違う

BoW：文書を表す

行＝文書 ／ 列＝単語

共起行列：単語を表す

行＝注目語 ／ 列＝周辺語

共起は左右1語。文書境界をまたがず、上と同じ前処理後の単語列で数える。

BoW → TF-IDF は文書検索へ。
共起行列 → PPMI → SVD は単語ベクトルへ。 TF-IDFとPPMIは、対象と計算式が異なる。

BoWは語順を保持しない。共起行列も文全体の語順や文法構造を保存するわけではなく、この左右対称の数え方では文の逆順を区別できない場合がある。

回数 → 重み → 検索スコア

1. BoW：語順を捨て、出現回数を数える

Bag-of-Wordsは文章を単語の集まりとして扱う表現。同じ語彙の順番で、各単語が文書に何回出たかを並べる。この教材では生の出現回数を使う。

dog bites man と man bites dog は意味が違っても同じBoWになる。

2. TFとDF：回数と文書数を区別する

TF(t,d) は文書dでの語tの出現回数。DF(t) は語tを含む文書数。同じ文書に10回現れても、その文書からDFに加えるのは1。

D は文書の総数。トークン数や共起回数の総和ではない。

3. IDF：多くの文書にある語の重みを抑える

IDF(t) = ln((1 + D) / (1 + DF(t))) + 1

lnは自然対数。この教材は平滑化ありの式を使う。少数の文書にしかない語ほど大きい。全文書にある語のIDFは1で、0にはならない。

TF-IDF(t,d) = TF(t,d) × IDF(t)

語の意味や重要性を直接理解した値ではなく、文書集合での出方から決まる重み。

4. 検索語も同じ語彙・同じIDFで表す

検索語qの出現回数に、文書集合から求めたIDFを掛ける。検索語を追加の文書として数え直さない。文書集合の語彙にない検索語は計算対象外。

行列には長さを正規化する前の値を表示。検索のコサイン類似度で、ベクトルの長さを考慮する。

5. コサイン類似度：ベクトルの向きの近さ

cos(q,d) = (q · d) / (‖q‖ × ‖d‖)

内積は同じ単語の成分を掛けて足した値。‖d‖は成分の二乗和の平方根。非負のBoW・TF-IDFでは0〜1で、大きいほど向きが近い。確率ではない。

検索ベクトルがすべて0なら式は定義できないため、この教材ではスコア0・一致なしとして扱う。同点は同順位。

6. 文書と単語の表現を分けて考える

BoWの行ベクトルは「その文書でどの単語が多いか」。共起行列の行ベクトルは「その単語の周囲にどの語が多いか」。どちらも回数を使うが、1行が表す対象が違う。

この教材は文書表現の補足。既存のPPMI・SVD教材やCBOW教材とは別の流れ。

自由入力の上限：8文書・40語彙・合計200語。式の参照：scikit-learn公式解説：TF-IDF。この教材ではTFを生の回数とし、対数TFは使わない。
